# Portfolio of Kikandi Muhombo Dieumerci

Personal portfolio website for the mid-semester project at Bugema University.
Built only with HTML5 and CSS3 (no JavaScript, no framework).

## Structure

```text
portfolio/
├── index.html     Home
├── about.html     About
├── gallery.html   Gallery
├── contact.html   Contact
├── css/style.css  Shared styles for the four pages
├── images/        Screenshots and photos
├── videos/        motivation.mp4
└── README.md
```

## Open it locally

1. Open the `portfolio` folder.
2. Double-click `index.html`.
3. Use the menu to visit the four pages.

## To complete

- Replace every text in `[square brackets]` with your own content.
- Add `videos/motivation.mp4` and your screenshots in `images/`.
- Replace `YOUR-USERNAME/YOUR-REPOSITORY` in `gallery.html` with your real GitHub link.

## Note

The contact form is visual only. Sending messages needs an external service or a backend.
